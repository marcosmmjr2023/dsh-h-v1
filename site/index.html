FreeDSH

Rode o DeepSeek Harness no Windows em português, com roteamento entre modelos gratuitos e atualizações seguras.

FreeDSH é uma camada de distribuição comunitária e não oficial sobre o DeepSeek Harness (MIT): roteamento free-first, gateway local para modelos gratuitos, painel integrado e rollback de um clique.

Instalação em 1 minuto

No Windows, abra o PowerShell e cole o comando abaixo. Ele baixa o instalador do repositório e inicia a instalação interativa.

Windows — PowerShell 
powershell -ExecutionPolicy Bypass -Command "$f=\"$env:TEMP\dsh-setup.ps1\"; irm https://raw.githubusercontent.com/marcosmmjr2023/dsh-h-v1/main/installer/dsh-setup.ps1 -Headers @{'Cache-Control'='no-cache'} -OutFile $f; & $f"

Linux (Debian/Ubuntu e semelhantes):

Linux — bash 
bash <(curl -fsSL https://raw.githubusercontent.com/marcosmmjr2023/dsh-h-v1/main/installer/dsh-setup.sh)

Depois de instalar, abra um novo PowerShell:

dsh 
dsh up
dsh update
dsh doctor

Já usa o DeepSeek Harness e quer só os plugins? Instale como bundle — sem instalador, sem copiar overlay:

DSH bundle 
dsh plugin --profile web add github:marcosmmjr2023/dsh-h-v1

O que o FreeDSH adiciona

  • ⚡ Roteamento free-first

    Usa FreeLLMAPI local, OpenRouter :free e OpenCode antes de qualquer alternativa paga, com fallback automático e modos de custo auto, eco, balanced e ultra.

  • 🔌 Gateway FreeLLMAPI local

    Gateway na porta 3002 que reúne suas chaves de modelos gratuitos em um único endpoint local.

  • 📊 Painel integrado

    Badges laterais (⚡ Roteador, ☑ Modelos), o modelo em uso com o custo e uma coluna com últimos arquivos e status do núcleo.

  • 🇧🇷 pt-BR completo

    Núcleo traduzido — 1078 frases em português — e README.pt-BR.md para começar sem obstáculo de idioma.

  • 🚀 Instalação em 1 minuto

    Um comando no Windows e um no Linux, com instalador que detecta instalações existentes.

  • 🛡️ Atualização segura do núcleo

    A versão nova é testada numa instância isolada, com snapshots antes da troca e rollback de um clique.

  • ⏱️ Auto-update a cada 30 min

    Agendador de Tarefas no Windows ou cron no Linux mantém o núcleo em dia sem você lembrar.

  • 🧩 PowerShell 5.1 e 7.x

    Funciona tanto no PowerShell que já vem no Windows quanto no 7.x instalado por você.

O que você precisa

  • Windows 10/11 ou Linux Sistema com PowerShell 5.1/7.x no Windows, ou uma distribuição Linux com bash.
  • Node.js 20+ Node 20 ou superior instalado e disponível no PATH.
  • Git Git instalado, para baixar e versionar o projeto.

O núcleo do DeepSeek Harness é instalado à parte, via npm — o FreeDSH não redistribui o core, ele o estende.

Segurança e privacidade

  • Credenciais ficam locais: as chaves dos provedores vivem na sua máquina e não devem ser commitadas.
  • Sessões e estado de runtime nunca vão para o git — esses caminhos ficam fora do versionamento.
  • Antes de trocar o núcleo, um snapshot é criado: voltar para a configuração que funcionava é um clique.
