# GitHub Settings Checklist for FreeDSH

These are repository-level settings that cannot be changed from a normal pull request.

## About section

Set the repository description to:

> FreeDSH — free-first multi-model routing, automatic fallback, safe updates and pt-BR support for DeepSeek Harness.

## Topics

Add:

- `deepseek`
- `deepseek-harness`
- `dsh`
- `dsh-plugin`
- `ai-agents`
- `coding-agent`
- `llm-router`
- `openrouter`
- `groq`
- `cerebras`
- `free-llm`
- `ai-coding`

## Discussions

Enable GitHub Discussions under repository settings.

Recommended initial categories:

- Announcements
- Help
- Ideas
- Provider reports
- Show and tell
- Routing / benchmarks

Recommended seed topics:

1. **Welcome to FreeDSH — what are you using it for?**
2. **Which free provider is working best for you this week?**
3. **Share your FreeDSH routing stack**
4. **Compatibility reports by OS / DeepSeek Harness version**
5. **Feature ideas and routing strategies**

## Social preview

When a dedicated FreeDSH image is available, use it as the repository social preview so links shared on Reddit, X, LinkedIn and chat apps show the project identity rather than a generic GitHub card.

## After enabling Discussions

Update `.github/ISSUE_TEMPLATE/config.yml` so questions/support point to Discussions instead of creating support issues when appropriate.
