# FreeDSH — GitHub Discussions seed posts

Use these after enabling GitHub Discussions. They are intentionally short and designed to invite useful technical replies.

## Welcome to FreeDSH — what are you using it for?

FreeDSH started as a practical layer around DeepSeek Harness for free-first routing, automatic fallback, safer updates and a friendlier daily workflow.

If you are testing it, introduce your setup:

- OS;
- DeepSeek Harness / FreeDSH version;
- providers you configured;
- what kind of tasks you use it for;
- what is currently frustrating or working well.

Please do not post API keys, private prompts or personal paths.

## Which free provider is working best for you this week?

Free tiers change frequently, so provider reports are most useful when they are dated.

Please include:

- date;
- provider;
- model;
- free/trial/paid tier at test time;
- approximate latency;
- rate-limit/failure behavior;
- whether fallback worked as expected.

The goal is to build real-world compatibility knowledge, not a permanent ranking.

## Share your FreeDSH routing stack

What routes are you using and in what order?

For example:

`FreeLLMAPI → OpenRouter :free → OpenCode → paid fallback`

Explain what you optimize for: lowest cost, speed, reliability, coding quality or something else.

## Compatibility reports by OS / Harness version

Use this thread for quick compatibility reports that do not need a full bug issue.

Include:

- Windows / Linux / macOS;
- OS version;
- Node/npm version when relevant;
- DeepSeek Harness version;
- FreeDSH version/tag;
- install/update result;
- sanitized errors if something failed.

## Feature ideas and routing strategies

What would make FreeDSH materially better for daily use?

High-value ideas usually improve one of these areas:

- provider reliability;
- routing quality;
- observability;
- cost visibility;
- onboarding;
- safe updates / rollback;
- compatibility;
- reproducible benchmarks.

For implementation-ready requests, open a Feature Request issue after the idea is refined here.
