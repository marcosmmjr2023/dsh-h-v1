# FreeDSH Launch Media Assets

## Demo GIF / short video

Target: 20–30 seconds.

Suggested sequence:

1. Open FreeDSH.
2. Show the integrated side panel and current router/profile.
3. Send one short task.
4. Show which provider/model answered.
5. If available, show one fallback event or the parallel-core update flow.
6. End on the repository URL or project name.

Requirements:

- readable on GitHub without full-screen playback;
- no API keys, usernames, personal folders, private prompts or account identifiers;
- crop out unrelated desktop content;
- optimize file size;
- show real behavior rather than a mockup whenever possible.

## Screenshots

Recommended set:

1. Main FreeDSH / DeepSeek Harness interface with integrated panel.
2. Router/model selection and profile controls.
3. Provider/fallback status.
4. Parallel core instance/update management.

Keep the README visually light: use only the strongest 1–2 images there and put the rest in detailed docs.
